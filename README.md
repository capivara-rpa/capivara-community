# Capivara Community

Este é o espaço público da comunidade para **sugerir, discutir e amadurecer**
melhorias da Capivara. O código e as releases estáveis ficam no repositório
oficial.

> **Deixa que a Capivara faz.**

## Como funciona

| Repositório | Papel |
|---|---|
| [`capivara-rpa/capivara`](https://github.com/capivara-rpa/capivara) | Código, documentação e releases **estáveis** |
| `capivara-rpa/capivara-community` | Ideias, RFCs, exemplos e discussões da comunidade |
| branch `next` do repo oficial | Integração das propostas **aceitas** antes do próximo release |

O fluxo é simples: a comunidade propõe aqui, os mantenedores avaliam e o que for
aceito vira código no repositório oficial. A `main` do oficial continua sendo a
versão estável; a `next` recebe o que está em validação.

## O que trazer

- **Melhorias no motor** — novas funções, atalhos, integrações e utilidades.
- **Control Room** — filas, agendamentos, agentes, credenciais, painel.
- **Documentação** — tutoriais, exemplos, correções e traduções.
- **Exemplos e plugins** — robôs de exemplo, conectores e casos de uso.
- **Bugs** — reprodução, ambiente e comportamento esperado.

## Como participar

1. Leia o [`CONTRIBUTING.md`](CONTRIBUTING.md).
2. Para uma ideia aberta, use as **Discussions**.
3. Para uma proposta concreta, abra uma **issue de sugestão** ou um **RFC** em
   [`ideias/`](ideias/).
4. Se a proposta for aceita, ela segue como PR no repositório oficial.
5. Dúvidas sobre o processo: [`GOVERNANCA.md`](GOVERNANCA.md).

## O que este repositório não é

- Não é um fork estável da Capivara.
- Não é canal de suporte urgente ou plantão.
- Não é lugar para segredos, tokens, dados de clientes ou informações pessoais.
- Não é garantia de prazo: toda proposta passa por avaliação.
